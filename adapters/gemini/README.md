# SENTRY for Gemini CLI

This folder is a Gemini CLI extension. Install it with
`python scripts/install_skill.py --agent gemini` (copies it to `~/.gemini/extensions/sentry/` together with
the skill files), or run `gemini extensions install <path-to-this-folder>`. Gemini loads `GEMINI.md` as context
and starts the `sentry` MCP server.
