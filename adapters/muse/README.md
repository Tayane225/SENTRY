# SENTRY for Muse

Use the generic integration: add `../generic/AGENTS.md` (or `SKILL.md`) to the agent's instructions and
register `sentry mcp` if MCP is supported; otherwise use the CLI with `--json`.

These integrations have not been verified against Muse: the platform's documented extension
mechanisms may differ by version. The generic adapter works with any agent that can run shell commands.
