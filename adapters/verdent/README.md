# SENTRY for Verdent

Load `../generic/AGENTS.md` (or `SKILL.md`) as project instructions/rules. If your Verdent build supports
MCP servers, register `sentry mcp` using `../generic/mcp.json`; otherwise let Verdent run `sentry … --json` commands.

These integrations have not been verified against Verdent: the platform's documented extension
mechanisms may differ by version. The generic adapter works with any agent that can run shell commands.
